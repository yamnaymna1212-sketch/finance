# Case File 001 — Rent vs Own · Voiceover script

Read it calm and sure, like telling a friend a secret. Short pauses at every period.
About 125 words, about 48 seconds. All numbers come from `previews/case-001-rent-vs-own/model.py`.

## Recording tips
- One take per row. Leave half a second of silence between rows so cutting is easy.
- Phone voice memo in a closet works. Speak 15 cm from the mic.
- Say numbers the American way: "twenty-two hundred," "fifty-two thousand."
